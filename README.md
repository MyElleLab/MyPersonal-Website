# (E)go: MyPersonal Success

Marketing and legal site for the iOS app.

Production: **https://ego.myellelab.com**

## Routes

| Path | Purpose |
|---|---|
| `/` | Landing page |
| `/privacy` | Privacy Policy. Linked from the app's consent flow and paywall. |
| `/terms` | Terms of Use. Same. |
| `/robots.txt` | Generated by `app/robots.ts` |
| `/sitemap.xml` | Generated by `app/sitemap.ts` |

**`/privacy` and `/terms` are load-bearing.** App Review opens both by following
links from inside the app, and a 404 on either is a rejection. They are also the
two URLs registered in App Store Connect. The app's copies of these URLs live in
`MyPersonal - Xcode/MyPersonal/Utilities/AppLinks.swift`. If a path here changes,
that file changes in the same commit.

Paths are bare, with no locale segment. This site is single-language and does
not use next-intl, unlike MyGrowth and MySellingMate which ship from the
`MyApps/Website/` boilerplate and therefore serve `/en/privacy/`. If this site is
ever localised, next-intl goes back with `localePrefix: "as-needed"` so the
English URLs stay bare and `AppLinks.swift` does not have to change.

## Stack

Next.js 16 App Router, React 19, Tailwind 3, TypeScript. No web fonts, no
analytics, no runtime dependencies beyond the framework.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

## Design

Strictly monochrome. There is no accent colour and adding one is not a small
change: emphasis is carried by weight, size and space.

| Token | Light | Dark |
|---|---|---|
| ground | `#FFFFFF` | `#000000` |
| surface | `#FAFAFA` | `#0A0A0A` |
| ink | `#0A0A0A` | `#F5F5F5` |
| muted | `#6B6B6B` | `#A0A0A0` |
| rule | 8% black | 12% white |

These mirror the app's `Extensions/Color+Theme.swift` exactly. That file is the
source of truth; if a value here disagrees with it, this file is wrong.

Type is `ui-serif` for display and `ui-sans-serif` for chrome, which resolve to
New York and SF Pro on Apple platforms. That is the same pairing the app uses,
so no web font is loaded.

Dark mode follows the system (`darkMode: "media"`). There is no toggle, because
the app does not offer one either.

## Copy rules

No em dashes and no en dashes anywhere, in copy or in comments. Use a colon, a
comma, or two sentences. Checked with:

```bash
grep -rnP '[\x{2012}\x{2013}\x{2014}\x{2015}\x{2212}]' . \
  --exclude-dir=node_modules --exclude-dir=.next --exclude-dir=.git \
  --exclude=package-lock.json --exclude='*.png'
```

The app's name in prose is always "(E)go: MyPersonal Success" or "(E)go". The
home screen label is "go" because the icon supplies the E; that reads as a typo
in a sentence and is never used in body copy.

## Legal content

Every claim on `/privacy` was checked against the app's source before it was
written. Both page files carry a PROVENANCE comment mapping each claim to the
file that supports it. Do not soften, extend or rewrite a claim there without
re-checking the code.

Two things are flagged as open in those comments rather than guessed: the
controller's registered establishment, and choice of law. MyElleLab is not a
registered company, so neither is asserted.

## Deployment

Vercel, connected to this repo. DNS is Cloudflare, `CNAME` on `ego`, DNS only
and not proxied, matching the six sibling app sites.

**This repo must stay public.** The Vercel Hobby plan does not deploy private
repos owned by an organization, and the failure is silent: pushes stop
triggering builds with no error anywhere.
